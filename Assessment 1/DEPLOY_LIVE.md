# 🚀 ऐप को लाइव कैसे डिप्लॉय करें (Deploy Live)

जब भी आप कोई लिंक खोलेंगे तो यह प्लेटफॉर्म दिखेगा। स्टेप्स नीचे दिए गए हैं।

---

## सबसे आसान तरीका: **Streamlit Community Cloud** (मुफ्त)

### 1. कोड GitHub पर पहुँचाना

- अगर पूरा repo पहले से GitHub पर है (Agentic-AI), तो बस **Assessment 1** फोल्डर का सारा कोड उसी repo में कमिट करें।
- टर्मिनल में (repo की जड़ में, यानी `Agentic-AI` फोल्डर में):

```bash
git add "Assessment 1/"
git commit -m "Add Streamlit RAG app for deployment"
git push origin main
```

- अगर `apple_db` फोल्डर अभी नहीं बनाया है तो पहले नोटबुक एक बार चला कर वेक्टर DB बना लें, फिर उसे भी कमिट करें (ताकि लाइव ऐप बिना PDF चुनने के चले)।  
  वरना ऐप लाइव पर पहली बार PDF से खुद ही index बनाएगा (थोड़ा समय लगेगा)।

---

### 2. Streamlit Cloud पर ऐप डिप्लॉय करना

1. ब्राउज़र में जाएं: **https://share.streamlit.io**
2. **Sign up** करें (GitHub से लॉग इन सबसे आसान है)।
3. **"New app"** पर क्लिक करें।
4. सेटिंग्स भरें:
   - **Repository:** `YourUsername/Agentic-AI` (अपना GitHub username और repo नाम डालें)
   - **Branch:** `main`
   - **Main file path:** `Assessment 1/rag_streamlit_app.py`
   - **Advanced settings** खोलें और:
     - **Requirements file:** `Assessment 1/requirements.txt`
5. **Deploy** पर क्लिक करें।
6. कुछ मिनट बाद एक लिंक मिलेगा जैसे:  
   `https://your-app-name.streamlit.app`  
   इस लिंक को किसी के साथ शेयर करें – जब भी कोई इसे खोलेगा, प्लेटफॉर्म खुलेगा।

---

### 3. ज़रूरी बातें

- **PDF:** ऐप में इस्तेमाल होने वाला PDF (`HBR_How_Apple_Is_Organized_For_Innovation-4.pdf`) repo के **Assessment 1** फोल्डर में होना चाहिए (पहले से है तो ठीक)।
- **Vector DB (apple_db):**  
  - अगर आपने नोटबुक चला कर `apple_db` बना लिया है तो उस फोल्डर को भी Git में कमिट कर दें – लाइव ऐप तुरंत उसे इस्तेमाल करेगा।  
  - अगर कमिट नहीं करते तो ऐप लाइव पर पहली बार चलने पर PDF से खुद index बना सकता है (साइडबार में “upload PDF” या डिफॉल्ट PDF से)।
- **फ्री टायर पर LLM:** Mistral-7B (llama-cpp) बहुत भारी हो सकता है। अगर ऐप क्रैश हो या मेमोरी एरर आए तो साइडबार में **"Use LLM (Mistral-7B via llama-cpp)"** अनचेक कर दें – तब सिर्फ **retrieval** (सर्च + chunks) काम करेगा, जवाब जनरेट नहीं होंगे लेकिन प्लेटफॉर्म लाइव दिखेगा।

---

### 4. लिंक शेयर करना

- डिप्लॉय के बाद मिला लिंक (जैसे `https://....streamlit.app`) कॉपी करें।
- इस लिंक को किसी को भेजें – जब वे क्लिक करेंगे तो उन्हें सीधा आपका RAG प्लेटफॉर्म दिखेगा।

---

## दूसरा विकल्प: अपने कंप्यूटर पर सिर्फ नेटवर्क में शेयर करना

अगर सिर्फ लोकल नेटवर्क (जैसे घर/ऑफिस की वाइफाइ) पर लिंक देना है:

```bash
cd "Assessment 1"
streamlit run rag_streamlit_app.py --server.address 0.0.0.0
```

फिर ब्राउज़र में खोलें: `http://<आपके-कंप्यूटर-का-IP>:8501`  
(जैसे `http://192.168.1.5:8501`)। इस लिंक को उसी वाइफाइ पर दूसरे डिवाइस से खोला जा सकता है।
